# vehicle_002 航向校核

MATLAB R2023a 实际运行；起点 (27,17,3.1415926536)，目标 (15,9,3.1415926536)。

## 原因

原终点判定允许 1 m 和 15 度误差；绘图把实际末点标为 goal，未绘制配置目标。
原规划器节点容量只有 max_expansions+1，容量耗尽后静默丢弃后继；已改为按需增长。
重复出队的已关闭状态原先仍被扩展；现跳过，并修正正负 pi 的周期离散索引。
此前仅增加扩展上限不能解决终点姿态误差。

## 修改

容差收紧为 0.05 m、1 度。增加满足两端位置及切线航向的三次 Hermite 末端连接，
拒绝奇点、超曲率及采样碰撞连接；搜索圆弧按不超过 0.05 m 间隔重建输出。
连接为前进段，既有搜索允许倒车。未约束转向速率，也不声明最短路径。
目标和实际末点分别绘图，输出误差及 MAT 数据。

原路径提前终止，且只输出 1 m 搜索端点，因此长度不能作为同等到达精度的最优性比较。
所有 461 个修复后采样点通过现有静态车身碰撞检查，并通过起终点、航向、位置连续性、
曲率及行驶方向校核。当前场景无静态障碍物，仅矩形道路边界；未进行多车动态碰撞仿真。
-pi 和 +pi 代表相同方向，误差按 atan2(sin(delta),cos(delta)) 计算。
